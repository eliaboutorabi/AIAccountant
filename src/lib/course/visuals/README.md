# Inline teaching figures

`TeachingFigure.svelte` takes `{ visual: TeachingVisual }` using the shared `types.ts` contract. The figure's HTML ID is exactly `visual.id`, so chapter and atlas links can target it. The renderer adds no assessment or progress state. Prediction reveals are exploratory explanations, not mastery evidence.

- **Art:** lazy, uncropped image with catalog-provided intrinsic width/height; native modal enlargement with fit-to-window and original-size views, keyboard/touch panning, Escape handling and focus restoration; complete text transcript. The enlargement button sits outside the image to avoid obscuring labels. Paths respect the SvelteKit deployment base.
- **Diagrams:** six layouts with text labels. Flow follows a numbered snake at desktop widths and linear reading order on mobile. Cycle adds a return path. Timeline uses a connected spine. Bars share one signed scale including zero. Matrix cells keep literal numeric values, including exact zero; intensity uses absolute magnitude. A matrix that exceeds the screen can be scrolled with keyboard focus.
- **Interactive:** `InlineExperiment.svelte` takes `{ interaction }`, the seven-member interaction union in `TeachingVisual`. The catalog `interactive.ts` exports exactly seven `interactiveVisuals`, with independently checked chapter/section placements.

## What really runs

| Figure        | Executable mechanism                                                                                                       | Scope                                                                                                                                                                                                                                   |
| ------------- | -------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| M03 training  | Existing regression engine's full-batch MSE gradient and weight/intercept update; actual train/validation MAE              | 24 synthetic training rows, 16 independent validation rows. USD thousands; inputs normalized by 100 for optimization. No final test disclosed.                                                                                          |
| M05 threshold | Ten fixed scores are classified at `score >= threshold`; exact confusion counts, precision, recall and authored error cost | Scores/outcomes are authored, not a claimed calibrated trained model. Undefined precision stays undefined if nothing is reviewed.                                                                                                       |
| M08 forecast  | Existing engine's last-value, seasonal-naive and trailing-three-mean methods fit on the available prefix                   | Synthetic USD-thousand collections; prior 12 origins are recomputed from their own prefixes. Origin is capped at 58 so target index 59 is before the full lab's final period.                                                           |
| M09 join      | Actual customer-key or invoice-key joins and optional preaggregation                                                       | Two synthetic invoices, three payments. Bad key creates 6 rows and USD 900 invoice total; invoice key still repeats the split-payment invoice (USD 400); aggregate-first reconciles USD 300.                                            |
| M11 tokenizer | Lazy local `gpt-tokenizer/encoding/o200k_base` encode/decode                                                               | Pieces and IDs are actual. Some individual byte-fragment tokens display replacement characters; the full sequence round-trip verifies the text. The constant four-component embedding is explicitly an illustration, not model weights. |
| M12 attention | Exact 2D scaled Q/K dot products, causal masking before stable softmax, weighted V mixture                                 | Hand-authored Q/K/V, one head, no trained model. Masked future weights and contributions are exactly zero, not tiny rounded probabilities.                                                                                              |
| M18 agents    | Finite-state transitions, integer-cent addition, scope denial and explicit approval gate                                   | Planner proposals are authored illustrations. No live LLM, upload, bank or external ledger. Repeated approved posting is idempotent within the demo state.                                                                              |

The demonstration calculations are in `interactive-math.ts`; no prerecorded curves or invented runtime probabilities are shown as measured model results. The inline forecast is developmental exploration, never a final-test score.

## Verification

- `interactive-math.spec.ts`: causal normalization/masking/mixture arithmetic; threshold boundary, empty-review denominator, score invariance and error cost; joins/grain; denied/approved/blocked state transitions; actual regression update; prefix-only forecasting; real tokenizer round trip; module/section links.
- `visuals.svelte.spec.ts`: control-to-output behavior, native art dialog/transcript, six native layouts and all seven figures with axe WCAG 2 A/AA + 2.1 AA and 390px overflow checks.
- Svelte MCP autofixer: all three delivered Svelte components must return no issues or suggestions.
- Inspected actual Playwright screenshots at desktop and 390px. No image crop, overlay on labels, or page overflow. Signed bars include an explicitly labeled zero. Decorative icons are hidden from assistive technology; labels carry the meaning.
