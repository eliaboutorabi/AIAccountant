## Scientific and editorial requirements

- A picture of a mechanism is not a measurement. Authored examples and schematic values are explicitly labeled; actual model and financial results are computed in the native figures and existing labs.
- Diagrams distinguish parameter updates from inference, token IDs from numeric meaning, attention from a verified explanation, retrieval from factual support, transcription from authorization, and accounting profit from cash.
- Generated labels and arithmetic are visually inspected, with incorrect drafts rejected or revised.
- Every image has equivalent text, actual dimensions, lazy loading, and an enlarged view; native diagrams reflow on small screens. Reduced motion, keyboard use and readable contrast are part of the release gate.
- Sources are original course records and the primary references already attached to each chapter. No unlicensed online artwork is copied or passed off as original.

The typed catalogs under `src/lib/course/visuals/` are the authoritative placement record. The [release review](release-review.md) records verification. Exact generation prompts and selected source paths are retained for [Day 1](prompts-day1.md), [Day 2](prompts-day2.md), [Day 3](prompts-day3.md), [Day 4](prompts-day4.md), and [Day 5](prompts-day5.md).
