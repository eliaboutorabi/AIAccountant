# Visual teaching expansion

The user found the substantive course too text-heavy. This revision must make mechanisms visible within the reading flow, rather than depend on a separate lab or decorative chapter thumbnail.

## Delivery contract

- One original generated teaching infographic for every module, M01–M25.
- Two additional purpose-built visual explanations per module, situated in different relevant sections.
- Seven inline interactive explanations: learning updates, decision thresholds, rolling forecasts, join multiplication, token IDs/embeddings, causal attention, and bounded agent execution.
- A complete inventory with title, module, section, learning purpose, technique, provenance, and delivery status; exposed in a visual atlas as well as retained here.
- At least 75 distinct instructional figures; the initial target including seven interactives is 82. Decorative hero artwork does not count.
- All explanatory labels and equivalent descriptions remain accessible. Generated figures need full text companions, an enlarged view, accurate captions, and mobile-friendly native diagrams.
- Inspect every generated image for correct labels, arrows, sequencing, numerical claims and missing/duplicated elements. Regenerate misleading artwork. Actual measurements stay in computed charts; authored schematic values must be labeled as illustrative.

## Shared generated-art direction

Use the built-in image-generation tool, one request per distinct asset. Do not claim a model identity that the available tool does not expose. These are original educational figures, not derivatives of an unlicensed online diagram.
