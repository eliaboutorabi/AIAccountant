# Builder chapter image prompts

Original generated teaching illustrations. No application artwork was used as input.

## Shared art direction

Use case: scientific-educational. Create a beautiful original 1536x1024 landscape editorial teaching plate for a sophisticated AI and accounting course. Ivory paper backdrop, forest-green large elegant serif title, sage ceramic, lavender glass, warm brass details, soft daylight and tactile 3D product-render quality. Adult, calm, polished museum-exhibit aesthetic. Generous whitespace, crisp legible large labels, purposeful objects. No logos, no people, no robots, no watermarks, no fake interface microtext, no illegible writing. On documents use abstract grey rules only unless exact words specified. Keep every requested label verbatim. No text beyond the stated labels. Do not add arrows unless explicitly requested.
