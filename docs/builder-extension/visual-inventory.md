# Builder visual inventory

The complete course now has 112 teaching figures: 35 generated illustrations, 70 native diagrams and seven inline interactive figures. This inventory covers the 30 figures added for M26–M35; the foundation inventory remains in [visual-expansion/inventory.md](../visual-expansion/inventory.md).

Each new chapter has three figures in three different reading sections. Every figure includes alternative text, a takeaway, an interpretive question and an authored answer. Illustrations also include text companions and image zoom. The five dedicated builder labs supply interactive practice beyond this figure inventory.
