# Laboratory interaction audit — 29 September 2026

Scope: all 22 registered `/lab/.../` routes, their 14 lab components, the embedded data-join panel, numerical/workflow engines, and the retained legacy `NetworkLab`. Tested against the running local Svelte app at `http://127.0.0.1:4180/`, with Chromium at 1440 × 1000 and 390 × 844. This is an executed UI and source audit, not a claim that every possible input or supported browser was tested.

## Fixes

- **Spreadsheet formula bar:** the initial selected A1 cell had an empty formula editor; pressing Apply could erase its header. Initial state, restored workbooks, workbook switches, and multi-cell paste now synchronize the editor with the selected cell. Regression test covers all four transitions.
- **Adaptation pause and generation:** a pause after five updates could retain the earlier score checkpoint. Pausing now measures the retained model; later training clears the old unlabeled generated sample. The transformer pause path is centralized, preserving its existing refresh behavior and refreshing after a training failure.
- **Evaluation evidence:** changing workflow configuration after running the development suite could leave an apparently current 8/8 result. The score retains an explicit configuration snapshot, visibly warns after configuration changes, and exports that snapshot and its stale/current state. Rerunning the suite measures the changed configuration (the tested duplicate-handling fault changes 8/8 to 0/8).
- **Regression plot and partial failures:** negative predictions were clamped at both line endpoints, distorting the learned slope. The chart now uses a signed vertical scale and a zero line. If a later update in a 25-update chunk is rejected as unstable, the last successful parameters and measured checkpoint remain aligned.
- **Numeric entry limits:** the business-value calculator now enforces its declared input bounds instead of allowing finite but enormous inputs to produce infinite results. Document arithmetic rejects amounts outside safe integer-cent precision and sums rounded minor units before displaying USD totals; oversized entries cannot pass reconciliation.
- **Control affordances:** training uses calculator icons; executable workflows use workflow icons. Actual 3D motion retains Pause and uses an orbit/Resume motion cue. No triangle playback affordance remains in the lab components or legacy network.
- **Mobile charts:** broad training/forecast/transfer diagrams retain readable label sizes inside named keyboard-scrollable regions. Four representation plots stack on phones. Actual measured mobile label sizes are approximately 13–15 px on the reviewed numerical plots, rather than 5–10 px. Exact data tables remain available. Chart scrolling instructions appear on narrow screens.
- **Disclosed evidence accessibility:** the supervised shifted-character sequence, numeric evidence tables, adaptation corpus lists, and exact local-agent prompt are keyboard-scrollable with descriptive region names. Opening MLP evidence tables no longer expands the mobile grid. Forecast timeline labels have sufficient contrast. The production desktop accessibility pass also found faint transformer tab subtitles; these were darkened and checked again.

## Limits

The headless browser has no WebGPU adapter with `shader-f16`; the optional large model was not downloaded and local-agent inference was not rerun. Capability handling and the no-model state were exercised, and its existing engine/component tests passed. All core CPU models, tokenizer, spreadsheet calculations, authored document checks and local workflow tools were exercised without that download. Synthetic data, authored decisions and actual model outputs retain their distinct scope labels. Browser storage exposure markers are learning evidence, not secure examination controls.
